# دارایی‌های تصویری تولیدشده برای Hexara

این پوشه فقط شامل دارایی‌های تصویری اصیل و مختص پروژهٔ Hexara است. تصاویر مرجع کاربر
برای جهت هنری، کیفیت پرداخت و ترکیب‌بندی بررسی شدند؛ هیچ نام، نشان، کارت، مهره یا
دارایی متعلق به بازی تجاری دیگری کپی یا بازتولید نشده است.

## مجموعهٔ زمین

مسیر نهایی: `terrain/*.webp`

- شش خانواده: `forest`، `hills`، `fields`، `pasture`، `mountains` و `desert`
- سه variation برای هر خانواده؛ در مجموع ۱۸ فایل
- اندازهٔ نهایی هر فایل: ۵۱۲×۵۱۲ پیکسل
- فرمت: WebP با کیفیت ۸۰
- انتخاب variation: قطعی و مبتنی بر مختصات axial در `assets/registry.ts`
- Number Token، بندر، راه، ساختمان و راهزن داخل تصویر زمین bake نشده‌اند.

هر خانواده با ImageGen داخلی Codex به‌صورت PNG مربعی ۱۲۵۴×۱۲۵۴ تولید شد. سپس یک
نسخهٔ اصلی و دو variation هندسی کنترل‌شده (flip افقی و عمودی) با `sharp` ساخته و
به WebP بهینه تبدیل شدند. این تبدیل فقط تنوع دیداری ایجاد می‌کند و قرارداد یا دادهٔ
برد را تغییر نمی‌دهد.

## منبع و مالکیت

- تولیدکننده: ImageGen داخلی Codex
- تاریخ تولید: ۲۰۲۶-۰۷-۳۰
- کاربرد: فقط رابط و برد پروژهٔ Hexara
- ورودی هنری: توضیح متنی مستقل برای هر terrain و سه تصویر مرجع ارائه‌شده توسط کاربر
- فایل‌های مرجع در خروجی محصول مصرف نمی‌شوند.

متن کامل promptها، نگاشت فایل‌های منبع و جزئیات تبدیل در
`design-references/asset-generation-prompts.md` ثبت شده است.

## بودجه و نگه‌داری

- حجم کل این مجموعه حدود ۱٫۵ مگابایت است.
- مسیر فایل فقط در رجیستری مرکزی ثبت می‌شود؛ کامپوننت‌ها نباید مستقیماً به WebP
  اشاره کنند.
- در صورت خطای بارگذاری، `Asset.vue` و رنگ پایهٔ Three.js fallback قابل‌استفاده
  فراهم می‌کنند.
- برای جایگزینی آینده، نام فایل، ابعاد و معنای terrain ثابت بماند تا منطق بازی و
  snapshotهای برد دست‌نخورده بمانند.

## مجموعه‌ی کارت منابع

مسیر نهایی: `resources/*.jpg`

- پنج تصویر portrait مستقل برای Lumber، Brick، Grain، Wool و Ore
- اندازه‌ی نهایی: ۵۱۲×۷۶۸ پیکسل، JPEG کیفیت ۹۰
- بدون متن، عدد، قاب یا لوگوی bake‌شده؛ این اجزا در `Card.vue` ساخته می‌شوند
- ثبت و مصرف متمرکز از `assets/registry.ts`
- حجم کل مجموعه حدود ۶۰۰ کیلوبایت
